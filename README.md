# ☕ Kopi Nusantara - Marketplace Prototype

Selamat datang di repository **Kopi Nusantara**. Ini adalah sebuah proyek website statis sederhana yang dirancang sebagai prototipe marketplace kopi lokal Indonesia. Proyek ini dibangun untuk tujuan uji coba tampilan dan fungsionalitas dasar pesanan melalui WhatsApp.

## 🚀 Fitur Utama
* **Landing Page Modern:** Tampilan beranda yang responsif menggunakan Bootstrap 5.
* **Katalog Produk:** Daftar menu kopi pilihan dengan detail harga.
* **Direct to WhatsApp:** Fitur pemesanan yang langsung terhubung ke WhatsApp penjual tanpa melalui database (Cocok untuk GitHub Pages).
* **Responsive Design:** Bisa diakses dengan nyaman melalui HP maupun komputer.

## 🛠️ Teknologi yang Digunakan
* **HTML5** - Struktur konten.
* **CSS3** - Kustomisasi tampilan.
* **Bootstrap 5** - Framework CSS untuk tata letak responsif.
* **GitHub Pages** - Untuk hosting website secara gratis.
